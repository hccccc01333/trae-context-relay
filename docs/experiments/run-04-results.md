# run-04：`resume --compact` vs Markdown 摘要（单轮案例）

> 这是一次单轮、单任务、模型未确认的受控 A/B，用于验证“缩短交接材料是否降低平台成本”。它不是普遍性收益结论；Token 用量不可得，平台积分只是成本代理。

## 实验设置

- 模型：**未确认**。分享页未显示模型版本，用户也未确认是否与 run-03 的 DeepSeek V4.1 Flash 相同。
- 基线：封存后的 v0.3 仓库，两臂 HEAD 为 `3a8b8d2`，文件树与 run-03 的 `b79132f` 完全一致，仓库内不含任务卡、协议、评分表与 fixtures。
- 任务：实现 `context-relay diff`，使用任务卡 v2（2565 字符，SHA-256 `f74130f3…`）。
- A 组：用 `context-relay resume --compact` 读取 H2 快照（快照 ID `snap_20261028T060713409Z_c7ae2f6c`）。
- B 组：使用停留在 H1 的 Markdown 摘要（1149 字符）。生成的 B `START.md` 与 run-03 B 的 SHA-256 完全一致。
- 顺序：B → A，串行；B 14:10 开始，A 14:38 开始；两臂均只收到一条入口提示，无额外纠偏。
- 材料长度：A compact 交接材料 1904 字符；同一快照的完整模式为 3795 字符，compact 减少 **49.8%**，但仍比 B 的 1149 字符长 **65.7%**。A 的入口材料总计 4475 字符，B 为 3720 字符。
- 单变量：相对 run-03，只改变 A 的交接材料生成方式；B 摘要、任务卡、封存基线、入口句与运行顺序保持不变。

## 结果

| 指标 | A：`resume --compact` | B：Markdown 摘要 |
| --- | ---: | ---: |
| 交接材料字符 | 1904（完整模式 3795） | 1149 |
| 最新有效决策保留 | 3/3 | 2/3 |
| 执行已废弃决策 | 0 | 1 |
| 重复任务 | 0 | 0 |
| 过期证据错误 | 0 | 0 |
| 错误完成声明 | 0 | 0 |
| 人工干预 | 0 | 0 |
| 验收 | 通过 | 通过 |
| 测试 | 32 | 28 |
| 平台积分 | 33.13 | 24.77 |
| 会话时长 | 14m 12s（852s） | 11m 9s（669s） |
| Token | 不可得 | 不可得 |

两臂均真实执行 `npm run check`（typecheck + 测试 + build），默认输出格式均与各自交接材料一致，4 类错误场景均以非零退出码失败。

## 关键发现

### compact 确实缩短了材料

`resume --compact` 保留了目标、2 个未解决冲突、3 条 `active` 决策、1 条 `superseded` 决策、任务状态历史、异常证据、下一步和备注；省略“已验证”文件逐项列表、决策理由、任务备注和完整 Git 文件清单。交接材料从 3795 字符降到 1904 字符，减少 49.8%。

A 仍然保留了 H2 的 3/3 `active` 决策，明确列出 2 个未解决冲突，没有执行已废弃的 `dec_d1c16f14d412`，也没有修改已有快照、`schema.ts` 或依赖。B 只拿到 H1，保留了 2/3，并把默认输出实现为已废弃的 JSON。

### 但没有降低平台成本

- A 的平台积分是 **33.13**，B 是 **24.77**；A / B = **1.3375**，A 高 **33.8%**。
- A 的会话时长是 **852s**，B 是 **669s**；A 慢 **27.4%**。
- 两臂相对 run-03 的积分都上升了（A +41.6%、B +37.4%），因此不能把 run-04 与 run-03 的积分差直接归因于 compact。
- 分享页活动统计：A 搜索 5 次、运行 14 条命令；B 搜索 1 次、运行 11 条命令。A 在核对冲突与证据上花了更多动作，但单次数据不足以证明因果。

因此，**本轮不支持“compact 更省平台成本”**。它能证明的是：在保留决策与冲突的前提下，交接材料可以缩短约一半；它没有证明 Token 或积分会下降。

## 限制

- 只有一轮干净 A/B；
- 只有一个任务，且模型版本未确认；
- Token 用量拿不到；平台积分由用户提供、未经独立核验，不能换算成 Token；
- 两臂相对 run-03 的积分都上升，平台计费或执行波动无法排除；
- 分享页只有最终摘要与活动统计，没有逐轮时间线，`turns_to_first_correct_action` 不可得；
- 样本不足以发布总体量化结论。

完整协议与假设见 [Benchmark 协议](benchmark-protocol.md)，原始评分表结构见 [benchmark-scorecard.md](benchmark-scorecard.md)。
